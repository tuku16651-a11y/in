# Dostuna Mesaj Yaz və Qazan

## Haqqında
Dostlar arasında kodlu mesajlaşma platformu. Static sayt — Render.com Static Site üzərində işləyir.

## Xüsusiyyətlər
- Qeydiyyat (ad, soyad, nömrə, numara, fön)
- WhatsApp vasitəsilə 5 dostla paylaşma
- 14 rəqəmli kod mesajı göndərmə
- Qrupa qoşulma tarixi (XX/XX)
- 2 rəqəmli şəxsi kod
- Supabase verilənlər bazası

## Texnologiyalar
- HTML5 / CSS3 / Vanilla JavaScript
- Supabase (PostgreSQL REST API)
- Render.com Static Site

## Deploy
Render.com → Static Site → Root directory: `.` → No build command
